Erster britischer Tausend-Bomber-Angriff auf Köln

1942-05-30 · ARCHIVEREIGNIS

1942 intensivierte das britische Bomber Command seine strategischen Luftangriffe auf deutsche Industriezentren.

1942 intensivierte das britische Bomber Command seine strategischen Luftangriffe auf deutsche Industriezentren.

In der Nacht vom 30. auf den 31. Mai wurde ein massiver Angriff auf Köln geflogen, an dem mehr als tausend britische Bomber beteiligt waren.

Die Operation demonstrierte den Umfang der britischen Luftstreitkräfte, doch großflächige Bombardierungen von Städten führten auch zum Tod von Zivilisten.

Der Angriff wurde zu einem markanten Ereignis des langen alliierten Luftkriegs gegen Deutschland; Folgen und Rechtmäßigkeit einzelner Methoden bleiben Gegenstand historischer Forschung.
