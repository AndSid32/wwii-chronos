# WWII CHRONOS 1.3.0 REDESIGN

Separate visual redesign branch based on 1.2.2.

## Scope
- Rounded cards, panels, controls, radio shell, previews and maps.
- Restrained glassmorphism using translucent archival surfaces and backdrop blur.
- Softer modern shadows and borders.
- Vintage radio wood/brass concept retained as the main visual anchor.
- Existing EN / DE / UA structure retained.

## Explicitly unchanged
- Historical data and article text.
- Timeline calculations and event positions.
- Map assets and map logic.
- Navigation and search behavior.
- Language structure.
- Audio logic.

The stable 1.2.2 build is not modified.
